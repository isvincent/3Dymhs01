# 桃園市立楊梅高級中等學校｜梅岡・高山頂台地 3D 數位地景與校園全覽

以 **Three.js (WebGL PBR + Post-Processing)** 打造的互動式 3D 校園與週邊環境數位模型，結合 **RWD 跨裝置響應式介面** 與 **PWA 漸進式網頁應用程式（支援安裝至主畫面與離線瀏覽）**。

本專案依據桃園市楊梅區**高獅路 5 號**（高山頂紅土台地南緣，昔稱「梅岡」）之真實地理高程、Google 地圖街廓與公開校史建築資料建模，完整呈現 5.4 公頃立體校園與周邊埤塘、道路、社區聚落關係。

## 核心功能與視覺特色

### 1. 真實地理與 16 處可互動 3D 地標
- **高山頂紅土台地模型**：重現北高南低的丘陵台地地形與側面紅土礫石層地質剖面，並繪製細膩等高線。
- **核心校舍與人文生態**：
  1. **悅知樓（新綜合教學大樓）**：地上 5 層綠建築旗艦，含圖書館挑空核心與連通蘊慧樓之 2F 景觀中廊。
  2. **蘊慧樓**：地上 4 層行政與專科大樓，具備半圓形中央門廳與太陽能光電屋頂。
  3. **梅岡精神堡壘與松林圓環**：1974 年設立之高聳「文筆鋒」碑體，象徵「愛自己、愛學校、愛國家」校訓。
  4. **御風樓・迎曦側翼與雙中庭**：圍合出防風採光的「日」字型雙中庭綠廊。
  5. **紅土藝術空間（啟明樓藝文館）**：承襲 1968 年原啟明初中記憶與謝孝德、何恆雄等藝壇校友美育傳統。
  6. **「仙旅奇緣」仙草農園與水生植物復育區**：呈現紫色花穗「桃園二號」仙草花畦與台灣原生水生植物保育池。
  7. **日新樓與圓形廣場**：順應梅岡巷弧線斜向配置，具圓筒狀西翼與同心圓景觀廣場。
  8. **工科實習大樓群**：電子科、資訊科專業工場與全幅太陽能光電屋頂。
  9. **學生活動中心與室內溫水泳池**：地上 2 層（700 人看台、羽籃球場與舞台）及地下 1 層（25×15m 溫水泳池）。
  10. **400m 標準運動場與白色扇形司令台**：含分道標線、6 面籃排球場、2 面網球場、足球門與四角照明燈塔。
  11. **北側太陽能光電風雨球場**：雙排大跨度單晶矽清漆反射光電頂棚。
  12. **高獅路 5 號正門與梅岡迎賓坡道**：銜接國道 1 號幼獅交流道與 T621／251／L608 客運路線。
  13. **梅岡巷通學廊道與梅中國宅社區**：西北側公車候車亭、斑馬線與鄰里住宅群。
  14. **東北側桃園台地埤塘與白鷺生態區**：即時 PBR 水面反射與展翅盤旋的白鷺鷥群。
  15. **高獅路東側樟樹相思林綠色廊道**：百公尺防風隔音森林緩衝帶。
  16. **週邊咖啡人文與東側光電廠區**：Hunter Kaffe 獵焰咖啡、郁明咖啡農園與幼獅方向太陽能廠房。

### 2. 三階段主題 3D 動畫（支援播放／暫停／時間軸拖曳／結構拆解常駐）
- **階段 1｜梅岡通學與操場脈動**：高獅路與梅岡巷公車行駛、400m 跑道慢跑、升旗台旗幟飄揚與白鷺鷥飛翔。
- **階段 2｜核心校舍 3D 結構拆解**：**悅知樓**五層樓板與**活動中心**金屬屋頂平順抬升分離，透視內部圖書館核心、教室隔間與地下溫水游泳池。
- **階段 3｜台地日照與太陽能綠電**：太陽軌跡牽動柔和陰影變化，並以金色能量脈衝展示校園太陽能綠電輸送路徑。

### 3. 四段時序光影與「步入人行視角」
- **晨曦／晴晝／夕照／星夜**：一鍵切換天空色溫、PBR 環境反射強度、420 顆星空穹頂、全校教室暖色窗光與道路路燈。
- **步入人行視角**：降至地面 1.7 公尺真人視線高度，於迎賓廣場仰望梅岡精神堡壘與校舍立面。
- **《梅岡誌》六大篇章與 4 條自動導覽路線**：涵蓋台地地理、交通路網、梅岡校史、學制與仙草課程、校友與人文，以及關鍵字即時搜尋。

## RWD 響應式設計與跨裝置操作

| 裝置類型 | 視窗斷點與自適應設計 | 3D 互動手勢 |
| :--- | :--- | :--- |
| **桌機／筆電** | 完整顯示標題卡、即時方位雷達小地圖、地標分類篩選器與時間軸控制列 | 左鍵拖曳旋轉、滾輪縮放、右鍵平移、點擊模型聚焦 |
| **平板直向／橫向** | 自動收合次要篩選欄、協調左右抽屜面板避免遮擋中央 3D 模型 | 單指拖曳旋轉、雙指縮放與平移、輕觸模型聚焦 |
| **手機直向** | 支援 `100dvh` 與劉海安全區 `safe-area-inset`；**自動調寬 3D 鏡頭 FOV 與全景距離**使東西向完整校區不裁切；說明卡改為底部抽屜 | 單指拖曳旋轉、雙指捏合縮放、輕觸建築或標籤聚焦 |
| **手機橫向** | 超薄頂欄與單列底部動畫控制，釋放最大 3D 可視面積 | 同上 |

## PWA 安裝與離線使用說明

1. **自動離線快取**：首次透過 HTTPS（如 GitHub Pages）或 `localhost` 開啟網頁後，`sw.js` 會自動快取首頁、圖示、Three.js 模組與字型，無網路環境下仍可流暢操作 3D 模型。
2. **安裝至主畫面／桌面**：
   - **Chrome / Edge（電腦與 Android）**：點擊畫面左上角自動浮現的 **「安裝 App」** 按鈕，或點擊網址列右側安裝圖示。
   - **iOS / iPadOS Safari**：點擊瀏覽器底部「分享」按鈕 → 選擇 **「加入主畫面」**，即可以全螢幕獨立視窗啟動。
3. **桌面應用程式捷徑（App Shortcuts）**：安裝後長按（手機）或右鍵點擊（桌面）圖示，可直接啟動「全景鳥瞰視角」、「悅知樓結構拆解」或「梅岡星夜模式」。

## 上傳 GitHub 與開啟 GitHub Pages 步驟

### 方法一：使用 Git 指令上傳

在專案資料夾開啟終端機（PowerShell / Terminal），依序執行：

```bash
git init
git add index.html manifest.webmanifest sw.js .nojekyll .gitignore README.md icons/
git commit -m "feat: 楊梅高中 3D 互動校園模型 (含 RWD 與 PWA 離線支援)"
git branch -M main
git remote add origin https://github.com/<您的GitHub帳號>/<您的儲存庫名稱>.git
git push -u origin main
```

### 方法二：使用 GitHub 網頁介面直接上傳
1. 建立新的公開（Public）GitHub Repository。
2. 點擊 **Add file → Upload files**，將 `index.html`、`manifest.webmanifest`、`sw.js`、`.nojekyll`、`.gitignore`、`README.md` 與整個 `icons/` 資料夾拖曳上傳並點擊 **Commit changes**。

### 啟用 GitHub Pages 線上展示
1. 進入該 Repository 的 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
3. Branch 選擇 **`main`** 與 **`/ (root)`**，點擊 **Save**。
4. 等待約 1 分鐘後，即可透過 `https://<您的GitHub帳號>.github.io/<您的儲存庫名稱>/` 開啟 3D 互動網頁並體驗完整 PWA 安裝功能。

### 本機開發預覽指令
因 ES Module 與 Service Worker 需透過 HTTP 伺服器載入，於本機測試時可任選以下指令啟動：

```bash
# 使用 Node.js (npx)
npx serve .

# 或使用 Python 3
python -m http.server 8080
```
接著於瀏覽器開啟 `http://localhost:8080`（或 `npx serve` 顯示之網址）即可預覽。
